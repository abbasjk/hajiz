# حجز

تطبيق حجز مواعيد للمحلات في البصرة. القرارات المتفق عليها في مستند «تطبيق الحجز: القرارات المتفق عليها».

| المجلد | المحتوى |
| --- | --- |
| `server/` | الخادم: Node.js + TypeScript + PostgreSQL |

## خطة البناء

| المرحلة | ماذا نبني | الحالة |
| --- | --- | --- |
| 1 | قاعدة البيانات والخادم الأساسي، ونشره على المنصة | اكتملت: يعمل على hajiz-production.up.railway.app |
| 2 | محرك الحجز: الأوقات المتاحة، المهل، الإلغاء التلقائي | اكتملت |
| 3 | تطبيق الزبون | لم تبدأ |
| 4 | واجهة صاحب المحل | لم تبدأ |
| 5 | الإشعارات | لم تبدأ |
| 6 | لوحة الإدارة | لم تبدأ |
| 7 | تجربة مع محلات في البصرة، ثم النشر | لم تبدأ |

## تشغيل الخادم محلياً

يحتاج Node.js 22 و PostgreSQL 16.

```sh
cd server
npm install
cp .env.example .env        # ثم عدّل DATABASE_URL
export $(cat .env | xargs)
npm run migrate:dev          # إنشاء الجداول والقيم الابتدائية
npm run dev                  # http://localhost:3000/health
npm test                     # يحتاج قاعدة hajiz_test فارغة
```

كل مسارات التطبيق تحت `/v1` وتحتاج الترويستين `X-App-Platform` (android أو ios أو web) و `X-App-Version`.
إذا كانت النسخة أقدم من أقل إصدار مسموح يرد الخادم برمز 426 `update_required`.

| المسار | الوظيفة |
| --- | --- |
| `GET /health` | فحص الخادم وقاعدة البيانات |
| `GET /v1/config` | الإعدادات والقوائم ووقت الخادم |
| `GET /v1/shops/:shopId/slots?date=2026-10-05&services=3,7` | الأوقات المتاحة ليوم واحد |

محرك الحجز في `server/src/booking/`: حساب الأوقات، المهل، تغييرات حالة الحجز، والمهام التلقائية التي تعمل كل دقيقة
(إلغاء الطلبات منتهية المهلة، والإكمال التلقائي). مسارات الحجز نفسها تُضاف في المرحلة 3 مع التعرف على المستخدم.

الأخطاء تُرسل برمز ثابت فقط مثل `{"error":{"code":"not_found"}}`، والتطبيق يترجمه من ملف الترجمة.

## النشر على Railway

1. أنشئ مشروعاً على Railway وأضف له خدمة PostgreSQL.
2. أضف خدمة من هذا المستودع واضبط **Root Directory** على `server`.
3. في متغيرات الخدمة أضف `DATABASE_URL` مرتبطاً بمتغير قاعدة البيانات: `${{Postgres.DATABASE_URL}}`.
4. الخادم يطبّق الترحيلات بنفسه عند كل تشغيل، والإعداد في `server/railway.json` يبني المشروع ويفحص `/health`.
5. فعّل النسخ الاحتياطي اليومي من إعدادات خدمة PostgreSQL.
